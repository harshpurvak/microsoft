# Microsoft Landing Page Clone

A simple static landing page inspired by the Microsoft homepage. The project uses plain HTML and CSS to build a navigation bar, hero section, call-to-action button, and quick-link product cards.

## Features

- Microsoft-style top navigation
- Large Surface Laptop hero banner
- Product shortcut section for Microsoft 365, Xbox, Windows 11, and Surface
- External icons from Remix Icon
- Responsive viewport setup with clean CSS structure
